# Akhila D. — Illustrated Story Portfolio

A zero-build, responsive storytelling portfolio designed like a hand-drawn engineering sketchbook.

## Run
Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy
The folder can be deployed as-is to GitHub Pages, Netlify, or Vercel as a static site.

## Customize
- Main story/content: `index.html`
- Pencil/sketch styling and responsive layout: `styles.css`
- Scroll/path/project animations: `script.js`
- Concept storyboard: `assets/storyboard.png`

The design intentionally uses CSS/SVG illustration instead of making the entire page one image, so text remains selectable, links work, and the layout adapts to mobile.
